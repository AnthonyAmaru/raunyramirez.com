# Rauny Ramirez · Studio & Practice

The source for [raunyramirez.com](https://raunyramirez.com): a responsive, local-first personal site for artwork, dentistry notes, diet tracking, goals, and music.

Uploaded artwork and music, as well as tracker entries, currently stay in the visitor's browser. A private backend will be required for secure accounts and cross-device syncing.
